<p>There are four widely used number systems: decimal (10), binary (2), octal (8), and hexadecimal (16). As humans, we use the decimal system.</p>

<p>The color blue in the examples below indicates which part we write first.</p>

<p>When converting <b>dec</b> to <b>bin</b>, write the powers of 2 from right to left until the next power would be greater than the number being converted. Then, starting from the left, write 1 above a value and subtract it from the original number. If a value is too large to subtract without producing a negative result, write 0 above it and continue. When converting <b>bin</b> to <b>dec</b>, reverse the process by writing the powers of 2 below the binary digits and adding the values that have 1 above them.</p>

<img src="/data/courses/nsc1.png" alt="Img" className="img-fluid img-article"/>

<p>When converting <b>bin</b> to <b>hex</b>, divide the number into groups of four digits, starting from the right. Under each group, write the first four powers of 2 and use the same process as in the previous conversion. Add the powers of 2 that have 1 above them within each group. The final number is formed by combining all the results. When converting <b>hex</b> to <b>bin</b>, reverse the process.</p>

<img src="/data/courses/nsc2.png" alt="Img" className="img-fluid img-article"/>

<p>When converting <b>dec</b> to <b>hex</b>, divide the number by %16 (modulo 16) and write the remainder on the other side of the line. Then write the rounded result of the division below the original number and continue using this result. Once finished, read the remainders from bottom to top. When converting <b>hex</b> to <b>dec</b>, take each digit or letter from right to left and multiply it by successive powers of sixteen. When converting <b>dec</b> to <b>oct</b> and vice versa, use the same methods, but divide and multiply by 8.</p>

<img src="/data/courses/nsc3.png" alt="Img" className="img-fluid img-article"/>

<p>When converting <b>bin</b> to <b>oct</b>, use the same method as for <b>bin</b> to <b>hex</b>, but divide the number into groups of three digits instead. Direct conversion between <b>hex</b> and <b>oct</b> is not possible, so it must be done indirectly through binary.</p>

<img src="/data/courses/nsc4.png" alt="Img" className="img-fluid img-article"/>

<p>When converting hexadecimal symbols to binary, represent each symbol using four bits (four digits). For octal symbols, use three bits.</p>
