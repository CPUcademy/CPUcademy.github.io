<p className="noBottomMargin" style={{ marginTop: "10px" }}>1MB = 8Mb (megabits)</p>
<p className="noBottomMargin">1GB = 8Gb (gigabits)</p>
<p className="noBottomMargin">32768B = 2<sup>15</sup>B = 2<sup>15</sup>*2<sup>3</sup> = 2<sup>18</sup>b</p>
<p className="noBottomMargin">2<sup>18</sup>b / 2<sup>10</sup> = 2<sup>8</sup>Kb (kilobits)</p>
<p className="noBottomMargin">2<sup>8</sup>Kb / 2<sup>10</sup> = 2<sup>-2</sup>Mb (megabits)</p>
<p className="noBottomMargin">2<sup>-2</sup>Mb / 2<sup>10</sup> = 2<sup>-12</sup> Gb (gigabits)</p>
<p className="noBottomMargin">0,25TB = 2Tb = 2<sup>1</sup>*2<sup>10</sup> = 2<sup>11</sup>Gb</p>
<p>2048GB = 2<sup>11</sup>GB = 2<sup>11</sup>*2<sup>10</sup>*2<sup>10</sup> = 2<sup>31</sup>KB</p>

<p className="noBottomMargin"><b>Exercise 1.</b> How long will it take to download a 1GB file with a 300Mb/s constant link?</p>
<p className="noBottomMargin">1GB = 1024MB = 8192Mb</p>
<p>8192/300 = 27,3s</p>

<p className="noBottomMargin"><b>Exercise 2.</b> Can we save 250 800KB files on a 32GB pendrive?</p>
<p className="noBottomMargin">32GB = 2<sup>5</sup>*2<sup>10</sup> = 2<sup>15</sup>MB*2<sup>10</sup> = 2<sup>25</sup>KB = 33554432KB</p>
<p className="noBottomMargin">33554432/800 ≈ 41943</p>
<p>Answer: Yes, we can.</p>
