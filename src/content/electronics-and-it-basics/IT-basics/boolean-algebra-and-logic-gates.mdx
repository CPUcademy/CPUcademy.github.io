<h2>Boolean algebra</h2>

<p>Boolean algebra is a mathematical system that operates on true (1) and false (0) values, serving as the foundation for digital circuits and computer logic.</p>

<p className="noBottomMargin">A and B can be equal 0 or 1.</p>
<p><span style={{ textDecoration: "overline" }}>A</span> = not A, contradiction of A, A reversed</p>

<p className="noBottomMargin"><b>Statement 1.</b> - Commutative Law</p>
<p className="noBottomMargin">A + B = B + A</p>
<p>A * B = B * A</p>

<p className="noBottomMargin"><b>Statement 2.</b> - Associative Law</p>
<p>(A + B) + C = A + (B + C)</p>

<p className="noBottomMargin"><b>Statement 3.</b></p>
<p className="noBottomMargin">A * (B + C) = A * B + A * C</p>
<p>A + (B * C) = (A + B) * (A + C)</p>

<p className="noBottomMargin"><b>Statement 4.</b> - Idempotent Law</p>
<p className="noBottomMargin">A + A = A</p>
<p>A * A = A</p>

<p className="noBottomMargin"><b>Statement 5.</b></p>
<p className="noBottomMargin">A * B + A * <span style={{ textDecoration: "overline" }}>B</span> = A</p>
<p>(A + B) * (A + B) = A</p>

<p className="noBottomMargin"><b>Statement 6.</b> - Absorption Law</p>
<p className="noBottomMargin">A + A * B = A</p>
<p>A * (A + B) = 1</p>

<p className="noBottomMargin"><b>Statement 7.</b> - Identity Law</p>
<p className="noBottomMargin">0 + A = A</p>
<p>0 * A = 0</p>

<p className="noBottomMargin"><b>Statement 8.</b></p>
<p className="noBottomMargin">1 + A = 1</p>
<p>1 * A = A</p>

<p className="noBottomMargin"><b>Statement 9.</b></p>
<p className="noBottomMargin"><span style={{ textDecoration: "overline" }}>A</span> + A = 1</p>
<p><span style={{ textDecoration: "overline" }}>A</span> * A = 0</p>

<p className="noBottomMargin"><b>Statement 10.</b></p>
<p className="noBottomMargin">A + <span style={{ textDecoration: "overline" }}>A</span> * B = A + B</p>
<p>A * (<span style={{ textDecoration: "overline" }}>A</span> + B) = A * B</p>

<p className="noBottomMargin"><b>Statement 11.</b> - De Morgan’s Law</p>
<p className="noBottomMargin"><span style={{ textDecoration: "overline" }}>A + B</span> = <span style={{ textDecoration: "overline" }}>A</span> * <span style={{ textDecoration: "overline" }}>B</span></p>
<p><span style={{ textDecoration: "overline" }}>A * B</span> = <span style={{ textDecoration: "overline" }}>A</span> + <span style={{ textDecoration: "overline" }}>B</span></p>

<h2>Logic gates</h2>

<p>Logic gates are the fundamental building blocks of digital circuits that perform logical operations such as AND, OR, and NOT. They are used for processing binary signals.</p>

<p className="noBottomMargin">Y is the result of letting A and B through a given logic gate.</p>
