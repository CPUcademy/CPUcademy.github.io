<h2>Types of viruses</h2>

<ul>
    <li><b>Salami shaving</b> - a technique where small amounts of money are siphoned off from numerous transactions without being noticed.</li>
    <li><b>Denial of service attack</b> - an attack that floods a network or service with excessive requests, causing it to crash or become unavailable.</li>
    <li><b>Trojan horse</b> - a malicious program disguised as legitimate software that allows unauthorized access or control of a system.</li>
    <li><b>Trapdoors</b> - hidden vulnerabilities or backdoors intentionally left in software to allow unauthorized access.</li>
    <li><b>Mail bombing</b> - flooding a user's email inbox with a massive volume of messages, often to overload or disrupt their email service.</li>
    <li><b>Software piracy</b> - the unauthorized copying, distribution, or use of software without proper licensing.</li>
    <li><b>Piggybacking</b> - gaining unauthorized access to a system by exploiting an already authorized session or connection.</li>
    <li><b>Phishing</b> - a scam where attackers trick users into revealing sensitive information, such as passwords or credit card numbers, via deceptive emails or websites.</li>
    <li><b>Defacing</b> - unauthorized modification of a website, often to display malicious or misleading content.</li>
    <li><b>Hijacking</b> - taking control of a user's session, system, or communication channel without permission, often for malicious purposes.</li>
    <li><b>Rootkits</b> - malicious tools designed to hide the presence of malware and allow persistent unauthorized access to a system.</li>
    <li><b>SQL injections</b> - a code injection attack that exploits vulnerabilities in an application's database query to execute malicious SQL statements.</li>
    <li><b>Dialer exploits</b> - malicious programs that manipulate modem settings to connect to premium-rate numbers without the user's consent.</li>
    <li><b>Spyware</b> - software that secretly gathers information about a user's activities, often for malicious purposes like identity theft.</li>
    <li><b>Keyloggers</b> - malicious programs that record keystrokes to capture sensitive information, such as passwords and credit card details.</li>
    <li><b>Crimeware</b> - malware designed specifically for illegal activities, such as stealing data or conducting financial fraud.</li>
    <li><b>Adware</b> - software that displays unwanted advertisements, often bundled with legitimate programs and used to generate revenue.</li>
</ul>

<h2>Types of attacks</h2>

<ul>
    <li><b>Cross-site scripting (XSS)</b> - an attack that injects malicious scripts into web pages viewed by other users.</li>
    <li><b>SQL injection</b> - an attack that injects malicious SQL statements into application queries to manipulate or access database data.</li>
    <li><b>Denial of service (DoS)</b> - an attack that overwhelms a system or service with requests, making it unavailable to legitimate users.</li>
    <li><b>Distributed denial of service (DDoS)</b> - a DoS attack carried out from multiple compromised devices simultaneously.</li>
    <li><b>Man-in-the-middle (MitM)</b> - an attack where an attacker secretly intercepts and potentially alters communication between two parties.</li>
    <li><b>Brute-force attack</b> - an attack that repeatedly tries different passwords or credentials until the correct ones are found.</li>
    <li><b>Dictionary attack</b> - a password attack that tries words and common password combinations from a predefined list.</li>
    <li><b>Credential stuffing</b> - an attack that uses stolen usernames and passwords to attempt access to other accounts.</li>
    <li><b>Session hijacking</b> - an attack where an attacker obtains a valid session identifier to impersonate an authenticated user.</li>
    <li><b>DNS spoofing</b> - an attack that provides false DNS information to redirect users to a malicious destination.</li>
    <li><b>ARP spoofing</b> - an attack that sends falsified ARP messages to associate the attacker's MAC address with another device's IP address.</li>
    <li><b>Ransomware attack</b> - an attack in which malware encrypts or blocks access to data and demands payment from the victim.</li>
    <li><b>Social engineering</b> - manipulating people into revealing information or performing actions that compromise security.</li>
    <li><b>Zero-day attack</b> - an attack that exploits a previously unknown or unpatched software vulnerability.</li>
    <li><b>Phishing attack</b> - an attack that uses deceptive messages or websites to trick users into revealing sensitive information or performing harmful actions.</li>
    <li><b>Buffer overflow exploit</b> - an attack that takes advantage of a program writing more data to a memory buffer than it can hold, potentially causing crashes or allowing an attacker to modify program behavior or execute malicious code. Buffer overflow vulnerabilities are among the most common types of software exploits.</li>
    <li><b>Privilege escalation</b> - an attack in which an attacker gains higher permissions than they are authorized to have, such as obtaining administrator or root privileges. The attacker starts with some level of access and attempts to increase their privileges.</li>
    <li><b>Jailbreaking</b> - the process of removing or bypassing restrictions imposed by a device or operating system, usually to gain greater control over the device or install software that is normally prohibited. Unlike privilege escalation, jailbreaking is specifically about breaking the restrictions of a locked-down system, and it is not necessarily performed for malicious purposes.</li>
</ul>

<h2>Protection techniques</h2>

<ul>
    <li><b>Firewalls</b> - systems that monitor and control incoming and outgoing network traffic based on predetermined security rules.</li>
    <li><b>Antivirus software</b> - programs designed to detect, prevent, and remove malware from systems.</li>
    <li><b>Intrusion detection systems (IDS)</b> - tools that monitor network or system activities for malicious behavior and policy violations.</li>
    <li><b>Penetration testing (pen-testing)</b> - simulated cyberattacks conducted by ethical hackers to identify vulnerabilities in systems or networks.</li>
    <li><b>Encryption</b> - converting data into a secure format that is unreadable without a decryption key, ensuring data privacy and security.</li>
    <li><b>Multi-factor authentication (MFA)</b> - enhancing security by requiring multiple verification methods before granting access to a system.</li>
    <li><b>Patch management</b> - regularly updating software and systems to fix vulnerabilities and improve security.</li>
    <li><b>Security awareness training</b> - educating users about best practices to recognize and avoid potential security threats.</li>
    <li><b>Vulnerability scanning</b> - using automated tools to identify weaknesses in systems, networks, or applications.</li>
    <li><b>Network segmentation</b> - dividing a network into smaller parts to limit access and contain potential breaches.</li>
    <li><b>Access control</b> - restricting user access to systems or data based on roles and permissions to minimize risks.</li>
    <li><b>Data backups</b> - regularly creating copies of critical data to ensure recovery in case of data loss or corruption.</li>
    <li><b>Secure coding practices</b> - writing software with security in mind to minimize vulnerabilities and exploits.</li>
    <li><b>Web application firewalls (WAF)</b> - protecting web applications from attacks like SQL injections and cross-site scripting.</li>
    <li><b>Endpoint detection and response (EDR)</b> - monitoring endpoints like computers and mobile devices to detect and respond to security incidents.</li>
    <li><b>Penetration testing frameworks</b> - tools like Metasploit or Burp Suite are used for ethical hacking and security testing.</li>
    <li><b>Security Information and Event Management (SIEM)</b> - platforms for real-time analysis of security alerts generated by network hardware and applications.</li>
    <li><b>Zero trust architecture</b> - a security model that assumes no user or device is trustworthy by default, enforcing strict access controls.</li>
    <li><b>Physical security</b> - protecting physical infrastructure, such as data centers and devices, from unauthorized access or tampering.</li>
</ul>
