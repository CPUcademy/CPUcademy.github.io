    </tr>
    <tr>
      <td>```pwd```</td>
      <td>Displaying the current working directory.</td>
    </tr>
    <tr>
      <td>```cd <dir_name>```</td>
      <td>Changing the current directory (navigating to root: ```cd /```).</td>
    </tr>
    <tr>
      <td>```mkdir <dir_name>```</td>
      <td>Creating a new directory.</td>
    </tr>
    <tr>
      <td>```rmdir <dir_name>```</td>
      <td>Removing an empty directory.</td>
    </tr>
    <tr>
      <td>```rm <file_name>```</td>
      <td>Removing files, and recursively removing directories with all contents (```rm -rf <dir_name>```).</td>
    </tr>
    <tr>
      <td>```cp <source> <destination>```</td>
      <td>Copying files or directories to a new location.</td>
    </tr>
    <tr>
      <td>```mv <source> <destination>```</td>
      <td>Moving or renaming files and directories.</td>
    </tr>
    <tr>
      <td>```touch <file_name>```</td>
      <td>Creating an empty file or updating its timestamp.</td>
    </tr>
    <tr>
      <td>```nano <file_name>```</td>
      <td>Opening a file in Nano editor, editing its content, creating if not exists, saving with ```CTRL + S```, exiting with ```CTRL + X```.</td>
    </tr>
    <tr>
      <td>```cat <file_name>```</td>
      <td>Displaying the content of a file.</td>
    </tr>
    <tr>
      <td>```echo <text>```</td>
      <td>Displaying text or variables in the terminal.</td>
    </tr>
    <tr>
      <td>```chmod <permissions> <file>```</td>
      <td>Changing file permissions.</td>
    </tr>
    <tr>
      <td>```chown <user> <file>```</td>
      <td>Changing file ownership.</td>
    </tr>
    <tr>
      <td>```ps```</td>
      <td>Displaying currently running processes.</td>
    </tr>
    <tr>
      <td>```top```</td>
      <td>Displaying real-time system processes and resource usage.</td>
    </tr>
    <tr>
      <td>```grep <pattern> <file>```</td>
      <td>Searching for a pattern in files or output.</td>
    </tr>
    <tr>
      <td>```find <directory_to_be_searched_recursively> -name <name>```</td>
      <td>Searching for files and directories in a directory hierarchy.</td>
    </tr>
    <tr>
      <td>```df -h```</td>
      <td>Displaying disk space usage in human-readable format.</td>
    </tr>
    <tr>
      <td>```du -h <file/dir>```</td>
      <td>Displaying disk usage of files or directories in human-readable format.</td>
    </tr>
    <tr>
      <td>```man <command>```</td>
      <td>Displaying the manual of a command.</td>
    </tr>
    <tr>
      <td>```sudo <command>```</td>
      <td>Executing a command with superuser privileges (admin).</td>
    </tr>
    <tr>
      <td>```ip```</td>
      <td>Displaying or configuring network interfaces.</td>
    </tr>
    <tr>
      <td>```apt-get install <package>```</td>
      <td>Installing software packages in Debian-based systems.</td>
    </tr>
    <tr>
      <td>```apt-get remove <package>```</td>
      <td>Removing software packages.</td>
    </tr>
    <tr>
      <td>```apt-get update```</td>
      <td>Updating package sources to latest versions.</td>
    </tr>
    <tr>
      <td>```apt-get upgrade```</td>
      <td>Upgrading installed packages to the latest version.</td>
    </tr>
    <tr>
      <td>```pip3 install <module>```</td>
      <td>Installing a Python module.</td>
    </tr>
    <tr>
      <td>```pip3 uninstall <module>```</td>
      <td>Uninstalling a Python module.</td>
    </tr>
    <tr>
      <td>```pip3 list```</td>
      <td>Listing installed Python modules.</td>
    </tr>
    <tr>
      <td>```pip3 list | grep <text>```</td>
      <td>Searching for a module by name in the installed list.</td>
    </tr>
    <tr>
      <td>```python3```</td>
      <td>Opening the Python3 interactive shell (use ```exit()``` to leave).</td>
    </tr>
    <tr>
      <td>```python3 <file.py>```</td>
      <td>Executing a Python script.</td>
    </tr>
    <tr>
      <td>```shutdown```</td>
      <td>Shutting down the system.</td>
    </tr>
    <tr>
      <td>```reboot```</td>
      <td>Rebooting the system.</td>
    </tr>
    <tr>
      <td>```hostname -I```</td>
      <td>Displaying the IP address assigned to the system.</td>

      <td>Editing scheduled tasks, managing recurring jobs.</td>
    </tr>
