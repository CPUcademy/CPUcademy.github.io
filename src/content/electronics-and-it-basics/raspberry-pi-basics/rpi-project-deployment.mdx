<p className="noBottomMargin">If you have a program that you would like to run automatically after turning on the Raspberry Pi, you have to follow these steps:</p>
<ol>
    <li className="noBottomMargin">Type this command into the terminal: ```sudo crontab -e```.</li>
    <li className="noBottomMargin">At the bottom of the file that has opened, write: ```@reboot sudo python3 /home/pi/Desktop/test.py```.</li>
    <li>If later on you want to stop the program, commend this line. Remember that if you run this program in the background and then use it from the code editor, some errors may occur.</li>
</ol>
