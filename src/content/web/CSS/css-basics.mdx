<p>CSS stands for Cascading Style Sheets. It is not a programming language. It allows us to style HTML documents. The extension of a CSS file is ```.css```. In CSS, a semicolon is placed after each statement. The term "cascade" refers to how styles are applied to elements in a structured and predictable manner. When multiple styles are defined for the same element, CSS follows a set of rules to determine which style takes precedence. The hierarchy of styles can be omitted with ```!important``` (added after a statement, e.g., ```color: blue !important;```). We can create comments between ```/*``` and ```*/``` signs. Things that we write between these signs don't count as code. Comments are often used to describe the code.</p>

<p>We can style the HTML tags, IDs (indicated with ```#```), and classes (marked with ```.```). An ID has to be unique to a subpage. It is assigned to an element like this: ```<p id="p"></p>```, and then styled in CSS: ```#p {...}```. A class is used to style many objects on a website. An element can have many classes. They are assigned to an element like this: ```<p class="p p2"></p>```, and then styled in CSS: ```.p {...} .p2 {...}```. An object can have both classes and an ID.</p>

<p>The ```*``` selector applies styles to all document elements, while the ```body``` selector specifically targets the ```<body>``` element and its children.</p>

<p>A container is typically used to wrap and structure the content on a web page, providing a centralized area to manage the layout and appearance of elements. Containers are often defined using the ```<div>``` element, which acts as a block-level element that holds other content. The primary purpose of a container is to create a defined space in which content is organized, usually for better alignment, padding, or width control. By setting specific width, margin, and padding properties, a container ensures that its child elements are consistently styled and positioned.</p>

<p>We can write CSS code inside the ```<style>``` tags in the head of an HTML document, inline (in the ```style``` attribute of a selected element), or in an external ```.css``` file (recommended because of style integrity). We can connect the external file (stylesheet) in the ```<head>``` section like this: ```<link rel="stylesheet" href="style.css" type="text/css">```. All the examples will be written in a <b>shortened</b> version to avoid redundancy and improve readability (the ```<style>``` tags will be right next to the HTML content).</p>

<p className="noBottomMargin">CSS hierarchy:</p>
<ol>
<li>Inline styles - ```style="color: blue;"```.</li>
<li>Styles from the ```<style>``` tag - ```<style>p{color: blue;}</style>```.</li>
<li>Styles from a file - ```p{color: blue;}```.</li>
<li>The default value.</li>
</ol>

<p>The object's ID is higher in the hierarchy than its class.</p>

<h2>The ```<div>``` tag</h2>

<p>The ```<div>``` tag is a block-level container used to group content and elements for organizational and styling purposes. It does not inherently have any visual representation or semantic meaning but serves as a versatile tool for structuring web pages. Developers often use ```<div>``` to apply CSS styles or JavaScript functionality to a specific section of the page by assigning it a unique ID or class. It allows designers to layout content effectively.</p>

<h2>Combining and grouping selectors</h2>

<p>Selectors can target elements in different ways. Writing ```div p``` selects all ```<p>``` elements that are descendants of a ```<div>``` (are placed inside a ```<div>```). On the other hand, writing ```div, p``` selects all ```<div>``` and all ```<p>``` elements independently, regardless of hierarchy. We can use descendant selectors to style nested elements and commas to group multiple independent selectors. Writing ```div.className``` targets only ```<div>``` elements with the class ```className```, leaving other elements unaffected.</p>

<h2>Overflow</h2>
              
<p>```overflow-x``` controls the horizontal scrollbar, and ```overflow-y``` the vertical one. Possible values: ```visible``` (content overflows), ```hidden``` (overflowing content is hidden), ```scroll``` (scrollbar always shown), ```auto``` (scrollbar appears when needed). The ```overflow``` attribute controls both scrollbars at once.</p>

<h2>Attribute selectors and custom attributes</h2>

<p>An attribute selector is a type of selector that allows us to select and style HTML elements based on the presence or value of specific attributes. This includes both standard HTML attributes and custom attributes (also known as data attributes) that we can define for our purposes. Custom attributes are prefixed with ```data-```. Attribute selectors are defined with square brackets. </p>

```css
<style>
    [data-blue] {background-color: blue; } /* all elements that have this attribute */                           
    p[data-red] {background-color: red; } /* paragraphs that have this attribute */
    [data-d="blue"] {background-color: blue; } /* all elements that have this attribute with "blue" assigned */
    [data-d="red"] {background-color: red; } /* all elements that have this attribute with "red" assigned */
    div[class*="a"] {background-color: red; } /* divs that have a class assigned, whose name has "a" in it */
</style>

```

<h2>Units</h2>

<p>A viewport is the area of ​​the browser window. It is defined as the area in which we view the website but without the window border and possible sliders. On the other hand, the canvas can be larger than the viewport. The canvas is the entire website area, even the one that does not fit in the viewport (on the screen).</p>

<h4>Relative units</h4>
<ul>
    <li>```em``` - Relative to the font size of the <b>parent</b> element (e.g., ```1.5em```).</li>
    <li>```rem``` - Relative to the font size of the <b>root</b> element (```html```) (e.g., ```2rem``` - 2x the root font size).</li>
    <li>```%``` - Relative to the parent element's width or height (e.g., ```50%```).</li>
    <li>```vw``` - 1% of the viewport's width (e.g., ```10vw```).</li>
    <li>```vh``` - 1% of the viewport's height (e.g., ```20vh```).</li>
    <li>```vmax``` - Relative to the larger of the viewport's width or height.</li>
    <li>```vmin``` - Relative to the smaller of the viewport's width or height.</li>
</ul>

<h4>Absolute units</h4>
<ul>
    <li>```px``` - Pixels, an absolute unit based on screen resolution (e.g., ```16px```).</li>
    <li>```in``` - Inches, an absolute physical measurement (e.g., ```1in```).</li>
    <li>```cm``` - Centimeters, an absolute physical measurement (e.g., ```2cm```).</li>
    <li>```mm``` - Millimeters, an absolute physical measurement (e.g., ```5mm```).</li>
</ul>

<p>Usually pixels are the default unit.</p>

<p>The ```calc()``` function allows us to perform calculations to determine property values dynamically. It can be used to combine different units and to create more flexible layouts and designs. We can use ```calc()``` to calculate widths, margins, padding, or font sizes based on a combination of fixed and relative units. Example: ```width: calc(100% - 20px);```. We can use these arithmetic operators: ```+```, ```-```, ```*```, ```/```.</p>
