<h2>Pseudo-classes</h2>

<p>A pseudo-class defines a special state of an element, allowing us to style it based on user interactions or its position in the document (e.g., ```:hover```, ```:first-child```). Below you can see all link-related pseudo-classes.</p>

<div className="table-container"><table>
    <tr>
        <td>```a:link```</td>
        <td>A normal link</td>
    </tr>
    <tr>
        <td>```a:visited```</td>
        <td>A visited link</td>
    </tr>
    <tr>
        <td>```a:hover```</td>
        <td>A link hovered over at the moment</td>
    </tr>
    <tr>
        <td>```a:active```</td>
        <td>A link during clicking</td>
    </tr>
</table></div>

```css
<style>
    a { color: black; }
    a:hover { color: red; }
</style>
```
                                  
<p>We style each of these states as a separate selector. To style form controls, we use pseudoclasses like ```:checked```, ```:disabled```, and ```:focus``` (an input element that is being used).</p>

<h4>```:first-child``` and ```:last-child```</h4>

<p>These two pseudo-classes indicate the first and the last element of a certain group.</p>

```css
<style>
    p:first-child { color: red; }
    p:last-child { color: blue; }
</style>

<div>
    <p>Lorem ipsum</p>
    <p>Lorem ipsum</p>
    <p>Lorem ipsum</p>
</div>
```

<h4>```:not```</h4>

<p>This pseudo-class styles elements that do not have a certain class assigned.</p>

```css
<style>
    p:not(.r) { color: green; }
    .r { color: red; }
</style>

<div>
    <p class="r">Lorem ipsum</p>
    <p>Lorem ipsum</p>
    <p class="r">Lorem ipsum</p>
</div>
```

</div>

<h2>Pseudo-elements</h2>

<p>A pseudo-element creates and styles specific parts of an element's content, such as its first letter, line, or content.</p>

<h4>```::before```</h4>

<p>This pseudo-element adds an element before an object. It is useful for adding custom icons to lists.</p>

```css
<style>
    ul { list-style-type: none; }
    li::before {
        content: "♞ ";
        color: red;
    }
</style>

<ul>
    <li>First</li>
    <li>Second</li>
</ul>
```

<ul className="u">
    <li className="f1">First</li>
    <li className="f1">Second</li>
</ul>

<h4>```::after```</h4>

<p>This pseudo-element adds an element after an object.</p>

```css
<style>
    ul { list-style-type: none; }
    li::after {
        content: " ♞";
        color: red;
    }
</style>

<ul>
    <li>First</li>
    <li>Second</li>
</ul>
```

<ul className="u">
    <li className="f2">First</li>
    <li className="f2">Second</li>
</ul>

<h4>```::first-letter```</h4>

<p>This pseudo-element styles the first letter of text in a block-level element (e.g., a paragraph).</p>

```css

    p::first-letter { font-size: 25px; }
</style>
```

<h4>```:root```</h4>
<p>```:root``` represents the highest-level parent in the document (usually the ```<html>``` element). It is commonly used for defining global CSS variables, which can then be reused anywhere in the stylesheet. This approach allows for consistent theming and easier maintenance of values like colors, fonts, and spacing.</p>

```css
<style>
    :root {
        --main-color: #157267;
        --font-size: 16px;
    }

    body {
        color: var(--main-color);
        font-size: var(--font-size);
    }
</style>
```

<h2>Inheritance</h2>

<p>A "child" is an object inside a "parent" object.</p>

<p>In CSS, styles can be inherited from parent elements to their child elements, allowing for consistency across a web page. For example, if a parent ```<div>``` has a color style, its child ```<p>``` elements will inherit this style unless explicitly overridden. This is part of the cascading nature of CSS, where styles are applied based on specificity and the order in which they appear. If a child element has a style set to ```initial```, like ```color: initial;```, it will reset the property to its default value, which is defined by the browser or the element's default style. On the other hand, using ```inherit``` will force the child element to inherit the exact value of the property from its parent. In the example below, the ```<p>``` tag will inherit the blue color from the ```<div>``` even if there are other styles concering its color defined elsewhere.</p>

```css
<style>
    div { color: blue; }
    p { color: inherit; }
</style>
<div>
    <p>This text will inherit the blue color from its parent.</p>
</div>
```

<p>Because CSS follows a cascading structure, we can define styles for specific combinations of elements. For example, writing ```.class a``` applies styles to an ```<a>``` tag inside an element with the class ```.class``` assigned, at any depth, whereas ```.class > a``` only targets ```<a>``` tags that are direct children of the ```.class``` element. Similarly, we can use a more complex selector like ```ol > li > ul```, which targets a ```<ul>``` list that is a direct child (does not include elements deeper within other elements) of an ```<li>```, which itself is a direct child of an ordered list (```<ol>```). These kinds of combinators allow us to precisely target elements, giving us flexibility and control over the styling of specific parts of the document.</p>
