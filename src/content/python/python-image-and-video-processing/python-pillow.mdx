<p>Python allows us to create and edit images using the ```Pillow``` library. It allows us to open images, resize them, crop them, rotate them, draw shapes, and save files in different image formats.</p>

<p>Write the ```from PIL import Image``` statement at the beginning of every example.</p>

```python
# Opening and displaying an image
imagee = Image.open("photo.jpg")
imagee.show()
```

```python
# Getting image information
imagee = Image.open("photo.jpg")
print(imagee.size) # displaying image dimensions
print(imagee.format) # displaying image format
print(imagee.mode) # displaying image color mode
```

```python
# Resizing an image
imagee = Image.open("photo.jpg")
resized = imagee.resize((300, 300)) # resizing the image
resized.save("resized.jpg") # saving the resized image
```

```python
# Cropping an image
imagee = Image.open("photo.jpg")
cropped = imagee.crop((50, 50, 200, 200)) # cropping the image
cropped.save("cropped.jpg")
```

```python
# Rotating an image
imagee = Image.open("photo.jpg")
rotated = imagee.rotate(90) # rotating the image by 90 degrees
rotated.save("rotated.jpg")
```

```python
# Converting an image format
imagee = Image.open("photo.png")
imagee.save("photo.jpg") # converting PNG to JPG
```

```python
# Drawing on an image
from PIL import ImageDraw

imagee = Image.open("photo.jpg")
draw = ImageDraw.Draw(imagee) # creating a drawing object
draw.rectangle((50, 50, 200, 200), outline="red", width=3) # drawing a rectangle
imagee.save("drawn.jpg")
```
