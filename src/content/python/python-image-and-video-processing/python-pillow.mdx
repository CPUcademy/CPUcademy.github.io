<p>Python allows us to create and edit images using the ```Pillow``` library. It allows us to open images, resize them, crop them, rotate them, draw shapes, and save files in different image formats.</p>

<p>Write the ```from PIL import Image``` statement at the beginning of every example.</p>

```python
# Opening and displaying an image
image_file = Image.open("photo.jpg")
image_file.show()
```

```python
# Getting image information
image_file = Image.open("photo.jpg")
print(image_file.size) # displaying image dimensions
print(image_file.format) # displaying image format
print(image_file.mode) # displaying image color mode
```

```python
# Resizing an image
image_file = Image.open("photo.jpg")
resized = image_file.resize((300, 300)) # resizing the image
resized.save("resized.jpg") # saving the resized image
```

```python
# Cropping an image
image_file = Image.open("photo.jpg")
cropped = image_file.crop((50, 50, 200, 200)) # cropping the image
cropped.save("cropped.jpg")
```

```python
# Rotating an image
image_file = Image.open("photo.jpg")
rotated = image_file.rotate(90) # rotating the image by 90 degrees
rotated.save("rotated.jpg")
```

```python
# Converting an image format
image_file = Image.open("photo.png")
image_file.save("photo.jpg") # converting PNG to JPG
```

```python
# Drawing on an image
from PIL import ImageDraw

image_file = Image.open("photo.jpg")
draw = ImageDraw.Draw(image_file) # creating a drawing object
draw.rectangle((50, 50, 200, 200), outline="red", width=3) # drawing a rectangle
image_file.save("drawn.jpg")
```
