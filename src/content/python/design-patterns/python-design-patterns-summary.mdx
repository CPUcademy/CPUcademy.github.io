<h2>Model-View-Controller (MVC)</h2>

<p>Model-View-Controller is a software architectural pattern used to separate concerns in application development. It divides an application into three interconnected components, improving organization, scalability, and maintainability. It is not a design pattern.</p>

<ul>
    <li><b>Model</b> - manages the data and business logic (e.g., fetching user info from a database).</li>
    <li><b>View</b> - handles the user interface and presentation (e.g., displaying the user’s name).</li>
    <li><b>Controller</b> - processes user input, updates the model, and selects the view to render (e.g., handling a login click).</li>
</ul>
