<h2><a id="bubble-sort">Bubble sort</a></h2>

<p>Bubble sort is a simple sorting algorithm that repeatedly steps through the input list element by element, comparing the current one with the one after it, swapping their values if needed (the larger elements "bubble up" to the top of the list). These swaps through the list are repeated until they don't have to be performed, meaning the list has become fully sorted.</p>

<img src="/data/courses/bubble_sort.gif" alt="Bubble sort" style={{ marginBottom: "20px" }} className="img-fluid"/>

<img src="/data/courses/bubble_sort_2.gif" alt="Bubble sort" className="img-fluid"/>

```cpp
const int size = 5;
int numbers[size];    

for (int i = 0; i < size; i++) {
    cout << "Enter " << i + 1 << " number: ";
    cin >> numbers[i];
}

int temp;

for (int i = 0; i < size - 1; i++) { // "size - 1" because it doesn't have to check the last number
    for (int j = 0; j < size - 1; j++) { // "size - 1" so that the "j + 1" later won't exceed the array's last index
        if (numbers[j] > numbers[j + 1]) {
            temp = numbers[j];
            numbers[j] = numbers[j + 1];
            numbers[j + 1] = temp;
        }
    }
}    

for (int i = 0; i < size; i++)
    cout << i + 1 << ". = " << numbers[i] << endl;
```

<h2><a id="searching-for-the-maximum-value">Searching for the maximum value</a></h2>

<p>We can search for the maximum value in an array in three ways. Firstly, we can use a normal array and a loop. Secondly, we can apply a similar method with vectors so that we don't have to know how many numbers there are. At last, we can use a pre-made method from the ```<algorithm>``` library.</p>

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int findMax(vector<int> numbers) {
    int max_value = numbers[0];
    for (auto number : numbers) {
        if (max_value < number)
            max_value = number;
    }
    return max_value;
}

int main() {
    // 1. An array and a loop
    const int size = 5;
    int array_of_numbers[size] = { 20, 2, -4, 150, 40 };

    int max_value = array_of_numbers[0];
    for (int i = 0; i < size; i++) {
        if (max_value < array_of_numbers[i])
            max_value = array_of_numbers[i];
    }
    cout << max_value << endl;

    // 2. A vector and a loop (inside the function)
    int first_nr = 4, second_nr = 2, third_nr = 50;
    cout << findMax({first_nr, second_nr, 40, third_nr, -20}) << endl;

    // 3. "max_element" from the <algorithm> library
    vector<int> temp_vector = {first_nr, second_nr, third_nr};
    cout << *max_element(array_of_numbers, array_of_numbers + size) << endl;
    cout << *max_element(temp_vector.begin(), temp_vector.end()) << endl;

    return 0;
}
```

<h2><a id="selection-sort">Selection sort</a></h2>

<p>Selection sort is an in-place comparison sorting algorithm. It is inefficient on large arrays. Selection sort is noted for its simplicity and has performance advantages over more complicated algorithms in certain situations, particularly where auxiliary memory is limited.</p>

<img src="/data/courses/selection_sort.gif" alt="Selection sort" style={{ marginBottom: "20px" }} className="img-fluid"/>

<img src="/data/courses/selection_sort_2.gif" alt="Selection sort" style={{ marginBottom: "20px" }} className="img-fluid"/>

```cpp
const int size = 4;
int numbers[size];

for (int i = 0; i < size; i++) {
    cout << "Enter " << i + 1 << " number: ";
    cin >> numbers[i];
}

int min_index, temp;

for (int i = 0; i < size - 1; i++) {
    min_index = i;
    for (int j = i + 1; j < size; j++) {
        if (numbers[j] < numbers[min_index])
            min_index = j;
    }
    temp = numbers[i];
    numbers[i] = numbers[min_index];
    numbers[min_index] = temp;
}

for (int i = 0; i < size; i++)
    cout << i + 1 << ". = " << numbers[i] << endl;
```

<h2><a id="insertion-sort">Insertion sort</a></h2>

<p>Insertion sort is a simple sorting algorithm that builds the final sorted array one item at a time by comparisons. It is much less efficient on large lists than more advanced algorithms such as quicksort. However, it is more efficient than selection sort and bubble sort.</p>

<img src="/data/courses/insertion_sort.gif" alt="Insertion sort" style={{ marginBottom: "20px" }} className="img-fluid"/>

```cpp
const int size = 4;
int numbers[size];

for (int i = 0; i < size; i++) {
    cout << "Enter " << i + 1 << " number: ";
    cin >> numbers[i];
}

int current, i, j;

for (j = size - 2; j >= 0; j--) {
    current = numbers[j];
    i = j + 1;
    while ((i < size) && (current > numbers[i])) {
        numbers[i - 1] = numbers[i];
        i++;
    }
    numbers[i - 1] = current;
}

for (int i = 0; i < size; i++)
    cout << i + 1 << ". = " << numbers[i] << endl;
```

<h2><a id="quicksort">Quicksort</a></h2>

<p>Quicksort is an efficient, general-purpose sorting algorithm. It is a divide-and-conquer algorithm. It works by selecting a "pivot" element from the array and partitioning the other elements into two sub-arrays according to whether they are lesser or greater than the pivot. The sub-arrays are then sorted recursively. It can be used in-place, requiring small additional amounts of memory to perform the sorting.</p>

<p><sub>The horizontal lines are pivot values.</sub></p>

<img src="/data/courses/quicksort.gif" alt="Quicksort" style={{ marginBottom: "20px" }} className="img-fluid"/>

```cpp
#include <iostream>
using namespace std;

const int size = 5;
int numbers[size] = {5, 60, 10, 40, 3};

void quicksort(int left_value, int right_value) {
    int i, j, temp, pivot;

    i = (left_value + right_value) / 2;
    pivot = numbers[i];
    numbers[i] = numbers[right_value];

    for (j = i = left_value; i < right_value; i++) { // "i" gets a value from "left_value" and "j" gets a value from "i"
        if (numbers[i] < pivot) {
            temp = numbers[i];
            numbers[i] = numbers[j];
            numbers[j] = temp;
            j++;
        }
    }

    numbers[right_value] = numbers[j];
    numbers[j] = pivot;
    if (left_value < j - 1)
        quicksort(left_value, j - 1);
    if (j + 1 < right_value)
        quicksort(j + 1, right_value);
}

int main() {
    quicksort(0, size - 1);

    for (int i = 0; i < size; i++)
        cout << i + 1 << ". = " << numbers[i] << endl;

    return 0;
}
```

<h2><a id="sort">```sort()``` - the ```<algorithm>``` library</a></h2>

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

bool descending(int first_nr, int second_nr) { // we pass this function to "sort()" without calling it (no parentheses), and "sort()" calls it itself, giving it two elements to compare each time
    return first_nr > second_nr;
}

int main() {
    // sort([array_name], [array_name] + [number_of_elements_to_sort], optional: the descending function);
    // *Ascending sort is the default option.

    // Sorting arrays
    int numbers_array[] = {9, 8, 7, 0, 8, 6, 3, 1, 7, 2};
    sort(numbers_array, numbers_array + 10, descending);
    for (int i = 0; i < 10; i++)
        cout << numbers_array[i] << endl;

    // Sorting vectors
    vector<int> numbers_vector {9, 8, 7, 0, 8, 6, 3, 1, 7, 2};
    sort(numbers_vector.begin(), numbers_vector.end(), descending);
    for (int i : numbers_vector)
        cout << i << endl;

    return 0;
}
```
