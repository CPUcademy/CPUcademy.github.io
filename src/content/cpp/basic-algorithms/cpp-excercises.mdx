<h2><a id="roman-numerals">Roman numerals</a></h2>

```cpp
int values[] = { 1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1 };
const char *symbols[] = {"M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I" };

int number, i;
cout << "Enter an integer: ";
cin >> number;
if (number <= 0)
    return 0;

for (i = 0; number > 0;) {
    if (number >= values[i]) {
        cout << symbols[i];
        number -= values[i];
    }
    else
        i++;
}
```

<h2><a id="reversing-a-string">Reversing a string</a></h2>

```cpp
string word = "abcdefgh";
for (int i = word.length() - 1; i >= 0; i--) // "length - 1" so that we don't see a space at the beginning (in was at the end)
    cout << word[i];
```

<h2><a id="checking-whether-a-word-is-a-palindrome">Checking whether a word is a palindrome</a></h2>

<p>A palindrome is a word, sentence, verse, or even number that reads the same backward or forward.</p>

```cpp
bool palindrome = true;
string word = "abba";

for (int i = 0; i < word.length() / 2; i++) {
    if (word[i] != word[word.length() - 1 - i]) {
        palindrome = false;
        break;
    }
}

if (palindrome)
    cout << word << " is a palindrome." << endl;
else
    cout << word << " is not a palindrome." << endl;
```

<h2><a id="searching-for-an-element-inside-of-an-array"></a>Searching for an element inside an array</h2>

```cpp
int numbers[5] = {4, -2, 8, 40, -20};
int found_index = -1, searched_number;

cout << "Enter the number you are searching for: ";
cin >> searched_number;

for (int i = 0; i < 5; i++) {
    if (searched_number == numbers[i])
        found_index = i;
}

if (found_index != -1)
    cout << "Your number was found under this index: " << found_index << endl;
else
    cout << "This element doesn't exist." << endl;
```
